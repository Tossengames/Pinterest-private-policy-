Privacy Policy

Effective Date: November 21, 2025

This Privacy Policy describes how the Personal Pinterest Script (“the Script”) handles information. This Script is a small, private tool created and used by a single individual to publish Pins to their own Pinterest account. It is not offered to other users and is not a public product.

1. Personal Use Only

The Script is intended strictly for personal use. It runs locally on the developer's own device or server and is not shared, sold, or distributed to anyone else. The Script interacts only with the developer’s Pinterest account.

2. Information Collected

The Script does not collect or store any personal data about Pinterest users. The only information used by the Script includes:

  • Images the developer chooses to upload
  • Titles and descriptions written by the developer
  • The Pinterest board selected by the developer

This information is provided manually by the developer when preparing content. No tracking, analytics, or data extraction occurs.

3. How Data Is Used

The data is used solely to create Pins on the developer’s own Pinterest account. The Script does not share, sell, or transfer data to third parties, nor does it scrape Pinterest or collect information about other users.

4. Storage and Retention

The Script does not upload or store data externally. All operations occur locally on the developer’s own device. Any temporary files (such as images) exist only on the developer’s machine and are managed manually.

5. Third-Party Services

The Script communicates only with Pinterest’s official API for the purpose of creating Pins. Standard development libraries may be used (e.g., HTTP or OAuth libraries), but no data is sent to external services other than Pinterest.

6. Security

API keys and tokens are kept private and stored locally. They are not included in public repositories or shared with any other users. The developer is responsible for securing their own environment.

7. No Tracking or Analytics

The Script does not include analytics, cookies, logging of personal behavior, or any tracking technologies.

8. Changes to This Policy

This Privacy Policy may be updated if the Script changes. The effective date will be adjusted when updates occur.

9. Contact

This is a generic privacy policy for a personal-use script. No contact information is required or provided.

Note: This Script is not a public service, does not have users, and does not interact with any third-party data. It only publishes content the developer manually prepares.
